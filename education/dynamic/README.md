# 无文字循环演示 · 燕尾榫

运行 `res://education/dynamic/demo.tscn`。只完成开放端滑动燕尾这一种结构解释；没有改主工作台、模型、相机、catalog 或 project.godot。宿主接线 API 仍见 INTEGRATION.md。

## 当前行为

打开即播放，7.2 秒自然循环；不自动换视角。图内没有标题、标签、坐标、部件名称或免责声明，图外只有 ⇄ 切换方向和 × 关闭。Esc 也可退出。关闭会停掉播放并禁用 presenter 的 process，重新打开从头播放。保留 `set_paused(bool)` 生命周期/验证 API，不显示播放暂停或重播按钮。

抗拔剖面：外力淡入，活动件小幅移动到斜面接触处停止；接触面短促高亮，槽壁作用在活动件上的反力向内向下；箭头淡出后，一次柔和短光带从各接触点沿槽座实体内到固定支撑。随后无施力地缓和复位，进入下一轮。光带及其柔光均裁切在槽座多边形内，没有粒子流水线，没有从活动件中心穿过空隙的装饰线。固定支撑用剖线符号表达。

滑出俯视：同一开放贯通槽，活动件可沿槽滑出；不显示虚构的接触阻挡或轴向传力。退出后沿同一路径返回，循环继续。两个方向仅通过图外图标手动切换。

绘图缩放上限为 1.0，并为小窗口保留余量；1280×800 时槽座宽约 520 px，较上一版缩小。没有触碰主场景相机。

## 科学边界（只写在文档，不显示在图中）

这是定性几何与时序演示，不是有限元或真实应力计算；光带不代表应力大小、传播速度或物质流动。没有材料、摩擦、刚度、平衡或承载力求解。复位是教学循环，不暗示真实弹性抖动。固定槽座是演示边界条件。

截面依据当前开放端滑动燕尾原理简化重绘，平行斜面与放大间隙用于说明接触，并非逐顶点还原网格。抗拔截止位移由间隙/斜率确定。滑出忽略摩擦、胶合及额外端挡。不能据此推断所有榫卯自锁。
