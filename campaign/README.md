# 三关入口与导航

`campaign.tscn` 是默认 F5 入口。三个关卡均可直接进入，也可通关后使用“进入下一关”。“关卡目录”返回选择页，保留当前运行期间各关状态；重新打开游戏不会恢复存档。

导航层只保管关卡实例、完成标记和切换；拼装规则、候选几何、局部相机及反馈由各关负责。离开关卡时将实例从场景树移出，避免隐藏关卡继续接收输入或影响灯光；再进入时复用同一个实例。第一关局部观察打开时隐藏外层导航，避免挡住观察窗口的返回按钮。

各关独立入口：

- `res://levels/level01/level01.tscn`：龙骨立架。
- `res://levels/level02/level02.tscn`：船板合壳。
- `res://levels/level03/level03.tscn`：帆樯舾装。

第二、第三关的开工前 2D 结构图与设计假设保存在 `docs/design/`。图示只说明本游戏连接方案与装配方向，不是古船历史考证。
