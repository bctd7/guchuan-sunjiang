# 无文字循环版验证

本轮修改：`diagram.gd`、`presenter.gd`、`test_dynamic.gd`、`README.md` 及当前记录/截图。修改前备份在 `../backup-loop-20261023/`。没有写入其他任务文件、主入口、主相机、模型或 catalog。

## 行为

- 无图中文字，无标题/坐标/部件名/免责声明；页面只显示 ⇄ 和 × 图标控件。
- 打开立即播放。每个方向固定 7.2 秒自然循环；不自动换视角。退出停止播放并关闭 `_process`，重开从头播放。
- 抗拔依次为：外力淡入 → 微位移直至接触停住 → 接触高亮和短反力 → 箭头淡出 → 接触点向槽座内部、支撑传播单次短光带 → 无施力缓和复位 → 下一轮。
- 不再从活动件中心画两条连续粒子流水线。脉冲中心线完全位于槽座内；软边也用槽座多边形裁切，不能穿过间隙或漂到空气中。
- 反力作用于活动件，仍垂直斜面、向内向下；固定支撑保留剖线符号。俯视滑出不画虚构阻挡/传力。
- 绘图最大比例为 1.0，小窗口额外留出 14% 余量。1280×800 下槽座宽 520 px，较上一轮约 650 px 缩小。

## 实际验证

Godot 4.7.2，Compatibility OpenGL，NVIDIA RTX 4070 Laptop GPU。

- 三个运行脚本分别 `--check-only`：退出 0，无编译错误。
- Headless：11,932 断言，0 失败。两方向各推进 60 秒，覆盖至少八个完整循环；逐步检查位移范围、复位/跨周期连续性、接触阻挡、箭头时序、光带时序和方向保持。
- 真实图形运行：11,934 断言，0 失败，退出 0。每方向实际渲染至少三个完整周期；未渲染时漏跑的周期不计入这一项。
- 检查暂停/继续 API、图标关闭、Esc、关闭后禁止后台推进、五次重复打开、图标切换、入口和换模停止。
- 两侧路径各取 201 个样本，全部位于槽座实体内；起点为高亮接触点、终点为固定支撑。检查反力垂直性、向内向下和箭头头部位于活动件。
- 四种尺寸：640×480、800×600、1280×800、1440×900。均检查了两个视角的七个阶段，共 56 个窗口/视角/阶段组合；保存 20 张关键截图。
- 已实际查看接触前、接触高亮/反力、光带中途、支撑到达、复位、滑出与小窗口截图；无图中文字、穿透、光带跨越间隙或图标裁切。

`results.json` 为最终运行结果。测试用受控时间驱动真实 Viewport 渲染，并非人工鼠标验收。未重复尝试此前 Windows 不兼容的 Library 物化流程，没有绕过限制；本轮直接检查本机生成的实际像素。
