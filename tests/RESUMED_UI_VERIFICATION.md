# 第一关 UI、长度试装与故事：当前验收

2026-10-28，断线恢复后交付。入口仍为项目 project.godot / F5 / campaign 关卡目录。

## 本轮改动

- 三关共用开场介绍保持每关三种原教学模型及观察、开始入口。深灰缩略图改为透明独立 3D 预览，直接使用原模型三角形；仅重建预览副本的平面法线消除旧 OBJ 平面三角阴影，不改原模型资源或课堂。暖纸色贯穿模型区，卡片填满可用高度，开始按钮收在右下，取消大块底部空白。
- 第一关顶部由三行高栏改为紧凑横排：关名、当前具体任务和返回目录。删除不易懂的“第几次示范”称谓，显示接船肋、接长龙骨、穿入横梁、检查骨架；手动三处、自动七件的规则没有调整。
- “进入观察与选材”打开完整暖色独立观察页；三种真实榫型、槽口、旋转、孔内观察保留。右侧各行共用一把尺，显示槽位和 A/B/C 长度；初始榫型、长度均无选中，不替玩家默认答案。返回主场景后点目标试装，关闭重开保留未提交选择，撤回/重置清空选择。
- 半榫 27/42/62格，对照盲槽45格；燕尾62/93/125格，对照开放滑槽95格；横梁582/632/702格，对照本处端部定位。100格为1模型单位，不是历史实物尺寸。尺图切换接头时会缩放，同一接头的各行比例一致。
- 三种榫卯的合法长短件均可装入；错误榫型仍拒绝。长半榫和长燕尾在孔底/槽端前停止，留下肩缝，不穿进实木；短件真实咬合较少。透榫仍为可穿封闭孔的等截面梁，端部有真实销孔，木销在插入结束后才显；短梁无法在肋外上销，长梁的销距肋外面留0.35模型单位轴向间隙。这里是不稳原因的教学构造，不宣称透榫普遍“越长越松”。
- 自动件继承玩家该组所选长度。装齐并播放完所有动画才开放检查；长度不合时所有件仍保留在架上，以松动动画和点名反馈说明不能稳定通关。撤回后可换料纠正。正确配合完成后仍切至船体局部俯视图。
- 主页面第二入口改为可选“船匠的小故事”；情景人物明确为创作，工艺事实另列并附官方来源，不宣称古船无金属钉。原课堂可从独立观察页“本关榫卯讲解”进入，九种原教育内容保留。
- 第二关实时端缝图仍只在工作副本暂存；本轮没有合入任何第二关生产文件、没有变更后两关装配规则，也没有改变原木材主场景和船坊背景。
