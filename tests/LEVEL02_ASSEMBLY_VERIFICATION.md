# 第二关装配改造与验收（2026-11-07）

> 历史阶段，已被同日后续需求取代：受阻即失败和搭扣倾斜不再使用。当前船用接头、可恢复试装、独立几何矩阵及验收路线见[新验证记录](LEVEL02_BOAT_JOINTS_VERIFICATION.md)。下文记录上一阶段，部分共享截图路径已由后续运行更新，不可据此判断当前行为。

本次按“错误装配也要构造可信，无法继续时直接组装失败”的确认方案实施。旧阶段“所有错型强行装满十件后试浪”的描述已被替换。本文件及实际源码为当前实现；之前的设计模拟保留在原方案目录。

## 已实现的结果

| 选择/情况 | 实际动作 | 后续结果 |
|---|---|---|
| 正确选配 | 原模型、原最终落位 | 正常补件、继续装配、末件后试浪 |
| 船板同型错口 | 沿实际入口到首个实体阻挡面，保留偏移 | 同排另一块复制原选择并独立验路；后排按实际已装几何继续 |
| 搭扣同型错口 A/B | 先接触下梁，再绕接触边倾斜约 6.8°，停在既有支架上 | 可继续；试浪报内部支撑松动，不冒出船壳水滴 |
| 错榫型 | 正式推入后到实际阻挡处停止 | 暂停 0.20 秒，再报“组装失败”；失败件不进入已装记录 |
| 三向中撑/顶撑错口 | 到实际槽壁接触处停止 | 组装失败，不安装后件 |
| 隔舱板错口 B/C | 底部错口到实际阻挡面停止 | 组装失败，不启动海浪 |
| 后件或自动半板另遇阻挡 | 检查其自己的插入路径，停在首个可达接触处 | 组装失败，保留此前实际完成的记录 |
| 船板端缝对齐 | 可以装齐，真实排布保留 | 末尾试浪从船板接缝漏水 |

选择、旋转、放大、浅拖均不提前判错。仍使用原正式松手阈值（0.72）。失败后锁定继续安装，可重开当前关或回目录；动画回调带代次校验，取消后不会补装或误通关。

## 几何与状态实现

- `assembly_policy.gd` 只分类正式提交的选择；`can_attempt` 维持中性的探索门禁。
- `contact_cells.gd` 按挤出网格的底面三角形拆分实体，保留凹槽空腔；`trial_contact.gd` 从外向内找第一道阻挡，避免越过肩部后落进不可达的空腔。
- 实体判定使用 0.00002 的网格数值容差，停靠另留 0.0012 间隙。本工程实际错口接触高度：中撑约 1.53118、顶撑约 1.61118、隔舱板约 0.40618；正确分别仍为 1.45、1.45、0.285。
- `hull_view.gd` 分开保存接触姿态和最终姿态；`cross_settlement.gd` 先验证倾斜路径，再播放接触、倾斜两段动作。
- 自动板先进入待补齐状态，检查其真实网格路径，再调用 `place_repeat`。不默改 joint/opening/layout，保留 automatic/demonstrated_by 来源。
- `trial_presentation.gd` 将船壳漏水点与内部支撑问题分开；漏水点随实际船板入口和外表面移动。
- 对照实施前基线，船用几何、承托几何、槽口对位、木纹材质、关卡映射及正确开口表均未改动；共享碰撞核心未改动。

- 63 个手动选配分类组合：474 项状态断言通过，覆盖中性探索、正式失败、正确通路、失败幂等、重复来源和重开。
- 108 种三排开口/端缝序列：2,052 项断言通过；每排代表件及自动半板分别走生产路径检查，两块保留相同选配与真实排深。
- 60 项新增接触检查：凹槽空腔、旋转后的实体、空腔前方阻挡、实际中撑/顶撑/隔舱接触高度、正确落位及搭扣倾斜。
- 40 种混合错误几何组合：120 项检查通过，使用独立三角网格检查，并以水平棱柱底面多边形交集区分保守扫掠的“只碰边”误报和实体穿透。
- 14 种错榫型的实际鼠标/模拟触摸操作：正确前缀、浅拖、正式中断、目录往返、重开均通过。
- 独立试浪四路线：全对（0 滴水）、只错搭扣（松动、0 滴水）、只错船板（2 漏点、10 滴水）、两者混合（船板漏水且内部松动）。
- GPU 运行并人工检查截图：实际错装接触/失败、自动件受阻、搭扣倾斜中间帧及最终停靠、正确整关、端缝错误、鼠标/模拟触摸、旋转缩放、不同视口尺寸。
- 回归原几何、开口、法线、局部观察、重复件生命周期、课堂往返、共享失败面板及关卡目录。完整最新状态索引见 [验证汇总](evidence/level02-assembly/verification-summary.json)。旧失败日志保留；修正后的复查报告另列，未以退出码 0 替代错误日志检查。

GPU 使用后台、不抢焦点的 macOS / Apple M1 OpenGL Compatibility 实例。首轮观察页夹具在布局就绪前点了目录，增加首帧布局等待后复查通过。碰撞核心夹具曾因沙箱禁止写入 Godot 用户测试目录失败，允许该测试目录写入后复查通过。

## 验收路线

1. **最短严重失败**：第一块船板选搭扣榫，选任意木料。先浅推，应该还能观察；再正式推入，停住后显示“组装失败”，另一半不能自动出现。
2. **搭扣可信错误**：三排船板正确完成后，隔舱十字上框选搭扣木料 A 或 B。观察先落到下梁、再略微倾斜靠住支架。后续正确装完，试浪应报“搭扣未扣牢，支撑松动”，不应从内部搭扣喷漏水。
3. **三向撑错误**：中撑选 A/B，或正确中撑后顶撑选 B/C；应在实际接触处失败，后件不得继续安装。
4. **最后隔舱错误**：前面全对，隔舱板选 B/C；应组装失败，不能直接播放整船试浪。
5. **完整正确路线**：三排船板开口依次 B / A / C；中排端缝靠右、上排靠左。搭扣选 C，中撑 C，顶撑 A，隔舱板 A。应完成七次手动操作、三次自动补板，正常通关。
6. **能够装齐的错误**：船板选同型错口或让相邻排端缝对齐，检查自动件没有偷偷纠正选择；装齐后应从实际船板接合处表现漏水。
