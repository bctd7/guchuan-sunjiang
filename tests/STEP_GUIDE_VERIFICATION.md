# 状态驱动步骤引导

公共实现：levels/shared/step_guide.gd。只持有绘制目标和呼吸相位，不保存游戏步骤，不推进游戏。各关从当前状态推导文字和目标。Label 自动复用现有 ReadingTranslation 难字注音。边框无填充、忽略鼠标、不接受焦点；整个候选区强调，不指认答案。按钮保留布局占位，透明时同时禁用、忽略指针并移除键盘焦点。

| 状态 | 提示 | 目标 | 辅助操作 |
|---|---|---|---|
| 一二关未选榫型 | 第一步选榫头 | 榫型区 | 观察/讲解/视角 |
| 已选榫型、未选材 | 第二步观察槽口选木料 | 木料候选区 | 同上 |
| 选材完成 | 第三步沿箭头推入 | 模型操作区 | 原有箭头与观察工具 |
| 二关中件就位 | 上方木件向下推入 | 模型操作区 | 有中件才可取回 |
| 装配动画 | 正在装配，请稍等 | 无 | 禁用干扰操作 |
| 试装完成 | 继续搭建 | 现有继续/返回搭建 | 存在可取回木件才显示取回 |
| 三关未选候选 | 观察下方候选，选榫头 | 候选区 | 讲解/放大 |
| 三关已选候选 | 点击绿色槽口 | 模型区 | 原有槽口标记 |
| 三关当前件就位 | 继续安装 | 继续按钮 | 有进度可撤回 |
| 舵叶就位 | 分别向左右操舵 | 操舵栏 | 左舵/回正/右舵 |
| 失败/成功 | 结果提示 | 无选材高亮 | 重开/目录 |

接入：第一关 joint_inspector.gd、level_ui.gd；第二、三关 level_ui.gd。原状态、判定、箭头、错误选材与输入协议不变。第一关动画结束同步更新引导及按钮，避免多等一帧。

按钮调整：撤回无内容时不可见且不可点击；继续安装仅可继续时出现；第一关取回调整仅试装后且不在动画时出现；第三关操舵按钮仅舵叶就位时出现。第一关动画中禁用返回、讲解、重新观察、孔内观察及相机按钮；二三关相应操作依照 busy 禁用。没有重新加入准备试装按钮。
