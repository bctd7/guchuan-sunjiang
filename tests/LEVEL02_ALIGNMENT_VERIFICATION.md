# 第二关真实槽口对位与搭扣/扣合辨识

日期：2026-11-01。读取用户指定的 Library 截图后核实：底列尾板位置选中了搭扣榫、木料 C，放大约 249%。截图里的木料属于错误类型试装。旧逻辑给错误木料套用统一横放搭靠姿态，其长轴和凹口没有朝向实际企口接收件；不能靠转动镜头解释或修好。

## 本轮修改

`assembly_alignment.gd` 只定义实际几何中的长轴、槽口入口方向及开口基准点，不持有关卡状态、镜头或验收规则。View 将待装木料自己的槽口坐标框对齐到接收件坐标框，再沿原目标接口的入口方向移动；不再用通用水平搁放代替对位。A/B/C 仍对应真实开口偏移，不把所有选项自动校正为正确件。

不匹配木料沿同一方向停在实体阻挡处，仍允许接受试装记录；末件落位后才统一试浪判定，撤回/重开保留。`trial_contact.gd` 使用保守边缘净空，避免依赖挤出网格的零间隙边界；没有放宽独立三角碰撞观察器。初始长轴、口面及横向位置来自木件本身的真实变换，不改主镜头掩盖偏斜。正确件原终态、State、Rules 及第一/三关行为未改。

搭扣模型保留两件半深交搭。扣合预览把固定下件、中件和顶件分成三层展示，三向及错层口更清楚；卡片和放大标题简要区分“两件半深交搭”和“三件分层扣合”。实际船体模型和目标名称没有替换，放大/旋转功能保留。

## 验证

- 16 个 headless 针对性执行项、6 个后台 Mac GPU 执行项、6 项 runner 自测通过。
- 90 种“部位×榫型×开口”组合独立检查真实长轴、口面法向及开口位置：基准槽口横向对齐，错误开口仍有偏差；镜头变换保持不变。
- 40 种混合错误组合的独立三角/包含检测通过。三向错口另采样 1,001 个完整进场位置，覆盖中间帧，端点通过不作为全部证据。
- 复现截图的错误搭扣：100%及约249%视图、触摸浅推/续推、接受错误试装、撤回，再用正确企口试装。六项 GPU 回归另覆盖所有错误类型、正确整关/错口试浪、缩放、旋转、候选大图、课堂/目录往返及三尺寸。
- 1440×900、1100×800、960×600 实图见[对照](evidence/alignment/compare.html)，[逐项结果](evidence/alignment/validation.json)和[保护文件哈希](evidence/alignment/protected_sources.json)保留原始证据。

首次 GPU 回归有一处三向中撑/下撑中间帧干涉记录；随后补充保守边缘净空和全路径采样，最终整套受影响 GPU 检查重跑通过。首次失败及未复现的诊断轮次保留，不改写成通过。碰撞观察器仅增加失败上下文输出，数学断言未放宽。

## 补充：不靠名称/颜色辨识

类型放大页增加真实部件槽口观察和咬合演示，作用于副本：搭扣可单独看上下两件半深凹口；扣合可看下件、中件、上件，翻看中件两面的不同切口。显示同一几何生成器的实际面，未绘制假凹口、未缩放槽口尺寸。整体模式可逐步合拢：搭扣上件一次落合；扣合中件落合后再落顶件，随后可拆开观察。切换部件、翻面、关闭或切换来源会终止旧 Tween；原选择、进度及装配实体不变。

新增 `levels/shared/joint_demonstration.gd` 只读取模型说明 metadata，控制副本显隐、相机与 Tween；不导入第二关 State/Rules。GUI 夹具核验两件/三件数量、真实部件隔离、单步/两步顺序、完成姿态、拆开恢复及关卡进度不变。新演示 headless 和 GPU 检查通过，现有放大/缩放 GPU 夹具也重跑通过，证据替换到最终逐项清单。
