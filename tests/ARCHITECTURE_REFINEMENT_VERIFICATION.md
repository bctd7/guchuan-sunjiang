## 改动与边界

- `tests/run_suite.py` 补齐注册项，支持 `--case`；GPU 使用显式 `--gpu`、后台独立实例、唯一日志。必须有新的成功报告、明确的非 headless renderer 及无焦点证据；脚本/资源错误即使退出码为 0 也判失败。超时只清理本次二进制、项目和唯一日志同时匹配的实例。Python 自测覆盖错误、旧报告、缺 renderer、焦点和精确超时清理。
- 第二关 View 产生 `trial_presentation.gd` 快照，试浪只消费接缝姿态、错误位置及木料引用/初始姿态，不再读取 HullView、State 或 Rules。快照复制可变数组和姿态；取消清理动效并恢复木料。它仍是定性海浪故事，不是工程计算。
- `inspection_camera.gd` 承担第二关镜头拟合、投影、宿主/子视口转换；关卡仍决定模式、可见构件及观察中心，没有复制第一关状态机。
- campaign 在离开当前关卡前检查新资源、实例和接口。失败保留当前场景/进度，允许再次尝试；无效实例释放，正常缓存与往返不变。
- 共用背景移至 `shared/assets/shipyard_background.png`，原图字节及 UID 相同；第一关与第二关科普引用新路径，画面样式保留。删除无调用的辅助卡脚本、第二关旧修复接口和候选动画字段。隐藏候选停止轨道输入与逐帧处理，清除未结束手势但保留角度。

## 穿模处理的依据

错型木料先按真实接收件顶面和木料底部接触区域安排水平搭靠，优先靠近原目标，不设置岸边暂放架。底列错型木料沿支承边横向接近，支撑/隔板位置从上方落下。隔舱处的错企口料横转以适应船壳净空。同型错开口保留原插入方向，在第一处实木阻挡前留小间隙；后续正确木料若被先前错料挡住，也停在实际接触处。

检测使用每个木材网格的实际顶点、面法线和边方向，避免旋转斜榫 AABB 的空白角造成假碰撞。凹多边形按凸包保守处理，可能提前阻挡；接触区域也是教学近似，未作重量、摩擦或稳定性模拟。正确整关保留原始装配姿态。冲击只沿退出方向作小幅运动，取消/结束恢复试装姿态。

错误仍可试装、逐件撤回并保留真实型号；十件最终落位后才试浪判错型、开口和端缝。失败仍提供重新开始及关卡目录；音效按原要求后置。

## 修复过的失败及可信范围

最初两项 core 夹具因沙箱无法保存隔离 user:// 临时资源失败，在该测试目录获得运行权限后重跑通过。目录课堂夹具仍在总览点击已迁入局部的隐藏按钮，已改为真实局部入口并核验返回原视图。整关失败夹具仍触发已删除的隐藏修复信号，已删除过时调用并完整重跑；旧执行虽然报告 failed=0，runner 仍正确捕获 SCRIPT ERROR。最终通过项选用重跑记录，原失败日志保留，不改写成通过。

macOS 系统证书读取警告按精确内容/调用位置单独记录，不忽略一般 ERROR。初期隔离导入的全局 editor_settings 保存警告属于沙箱限制，未修改用户编辑器设置。最终业务及 GPU 执行项没有未解决错误。
