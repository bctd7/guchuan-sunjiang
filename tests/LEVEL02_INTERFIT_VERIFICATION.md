## 结构与任务安排

当前接口固定，不随玩家选择改变。顶部类型卡中，与当前任务配套的类型用于选材；另两种标为“对照”，打开完整配对结构，可旋转、看各件槽口并逐步合拢。返回后，船上接收件、待装件姿态、选项、已装进度保持不变。

第一处仍铺企口船板：玩家比较 A/B/C 的槽位与真实底梁凸舌。搭扣和扣合不再被当作孤立木条硬塞进这处底梁。相同原则用于后续固定接口；船上的搭扣框和扣合撑仍有实际装配任务，并保留错槽候选。这是有意调整候选安排，不再以“选错任意榫型后硬试装”为本轮验收标准。底层错型几何防护仍保留给已有状态或直接 API 调用，当前 UI 不再创建这种新状态。

| 结构 | 接合与约束 | 错误在哪里暴露 |
|---|---|---|
| 企口 | 完整两板平行靠拢，凸舌进入长槽，槽壁包住凸舌 | 船板 A/B/C 槽位与端缝错误保留，能合理装齐的到试浪检查 |
| 搭扣 | 接收件沿 X，活动件沿 Z，90° 交叉；各去掉半厚，相互填入对方缺口；最终不是双层叠放 | C 齐平；A 浅槽部分落座；B 宽槽落座后有真实侧隙 |
| 三件扣合 | 下件 60°、中件 0°、顶件 −60°；中件有凸肩和窄颈，沿下件导槽侧推，顶件随后落入交叉锁口 | 中件 A/B 先能进入下件，顶件到错误通道才受阻；C 中件配 A 顶件闭合 |

船用搭扣和扣合的实体结构经重新检查后保留，类型对照中的搭扣改为同一船用几何生成器。三件扣合的导槽挡肩阻止中件直接上下进出；顶件的实体阻止中件水平退出。它是本项目教学模型的船用改造，不声称考古原位或加工图。课堂既有模型没有被连带改造。

所有位置和碰撞仍由真实构件确定。受阻只形成可恢复的局部状态，可观察、反向抽回、换件或撤回中撑；主动“结束本次试装”才结束无法完成的组装。自动补板独立验路，不能跳过阻挡。整船正确路线及宽槽松动/错缝漏水继续验证。

## 默认装配视野与细节

参考第一关 `joint_inspector.gd` 和 `inspector/inspection_geometry.gd`：保留完整活动件与接收骨架，而非默认只看两个短木头。第二关默认显示完整待装木料、实际接收件及相邻船架；远端船体仍按必要范围裁切，近侧遮挡的船板适度剖开，不把整个教学船段缩到看不清。

“看槽口”进入较近的细节并淡化周边；“返回装配视野”恢复先前的角度与缩放。构件位置和试装深度不被相机操作改变。默认视野无透明接收件，第一排固定端缝不遮住槽口。返回总览后恢复完整船体。

## 材质与阴影

- `timber_lighting.gd` 为主装配区、类型卡、候选卡和放大窗提供相同的固定主光、补光、环境光与阴影设置；没有挂在相机上的第一处专用灯。
- 木材保留明亮纹理，并降低此前高亮发白的浅色木材；局部接收件不再换成灰褐色或不同粗糙度。
- `wood_surface.gd` 把主要接合木料的各个槽壁、肩部和板面放到同一根木料的纹理坐标中；木件移动时纹理随木料移动，不随世界或相机滑动。
- `inspection_context.gd` 保留原构件局部坐标、材质与纹理相位；新切面使用硬边法线，镜像构件的原面与封口法线均向外。Box 转为带 UV 的网格后仍保留可封口标记，不能出现空心切端。
- 放大窗兼容第一关原候选预览：没有第二关 lighting_profile 属性时仍使用原灯光，避免共享查看器回归。

统一配置不意味着任意姿态的所有面同样亮。不同朝向和真实遮挡仍形成明暗与接触阴影；不通过关闭阴影来伪造一致。

## 效果验收路线

- 重启本次游戏进程进入第二关，打开第一处；默认应见完整待装船板和邻近船架。点“对照搭扣”看两缺口交叉嵌合，点“对照扣合”看中件侧滑、顶件锁止，再返回。
- 企口依次 B/A/C，端缝左/右/左；搭扣 C、中撑 C、顶撑 A、隔舱 A 可完成整船。
- 另一次中撑选 A 或 B，观察它先侧滑到位，再让顶件 A 接近并被真实槽肩挡住；抽回或撤回中撑后换 C，应能继续。
- 对比候选、放大、待装与落位的同一木料，旋转观察光源应固定，纹理不跳，接收件不再变灰；“看槽口”退出应回到原视野。
