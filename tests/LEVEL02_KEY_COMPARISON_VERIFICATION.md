# 第二关：关键尺寸与实际接头参照

> 此为历史版本。用户反馈此版仍难以理解，已由[正面缺口与同尺度参照](LEVEL02_DIRECT_COMPARISON_VERIFICATION.md)替代；下文证据仅对应当时实现。

2026-11-08。用户反馈“上口、深、偏”仍需解读，允许只保留足够判断的关键量；随后截图指出首处选搭扣时，上面仍是企口凸条，下面却是搭扣宽深，参照对象不一致。

## 变化

- 沿用第一关的三张真实模型卡、统一相机尺度、字号和放大入口。候选最多两行、72 基础行高；不靠缩小字号塞参数。
- 企口只显示槽口靠下／居中／靠上；上方改为正立板端图。三件共同的槽宽和槽深不重复列出。
- 搭扣保留开口宽与挖入深度。扣合只保留开口宽与中间／一侧；不再逐件列出相同的上下槽深，也不用“偏移 0/30”解释位置。
- 参照同时识别当前安装部位和实际试装模型。首处搭扣从固定座木三角面取得跨接处截面宽度，并用相邻未开槽部位与开槽处的高度差取得实际开槽深度。测量约为 33.255 格宽、9.062 格深，界面明确近似显示为约 33、约 9；候选仍按真实名义槽宽和挖入深度显示 36.4／58、3／9。
- 上述 33 格是座木横向占宽，9 格是座木开槽高度差；不是虚构一个“标准正确候选”。固定座木不因 A/B/C 改形，选择改变后数值也不变。切回企口恢复板边凸条参照。
- 首处扣合的两件已经按各自开口配套加工，不存在后三向接头的统一 28 格目标。此处改为简短的两件配套与动作顺序说明，移除误导的标尺。
- 后段异型试装无对应尺寸时，显示真实接收件的形状说明，不把不同轴的尺寸或后续标准顶件数字作为匹配依据。返回原接法后恢复正常参照。
- 后段正常扣合顶件仍保留实际已装中件的开口宽与位置，未把错误中件替换成正确模板。
