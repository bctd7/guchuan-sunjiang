# 古船榫匠

古船局部木构连接教学互动游戏，暂定优先使用 Godot 制作数字版。

每关聚焦一个局部榫卯或木构连接模型，不拼装整船。目标流程为「识别 → 对齐 → 拼接 → 验证 → 科普」，具体关卡、操作方式与美术方案仍待讨论。

涉及船型、连接方式与工艺的史实需要逐项核验。未验证节点仅作教学示意，不宣称精确复原。

## 启动

使用 Godot 4.7.2 打开 `project.godot`，按 F5。唯一主入口是 `scenes/main.tscn`，当前仅显示项目标题与待讨论状态。

## 目录

- `scenes/`：启动场景与后续场景。
- `interaction/`：后续交互模块，当前为空。
- `levels/`：后续局部关卡，当前为空。
- `models/`：后续模型素材，当前为空。
- `ui/`：后续界面模块，当前为空。
- `docs/`：项目说明与后续设计记录。
- `tests/`：后续必要验证，当前为空。

这是独立的新项目骨架，未复制旧项目代码或密钥，未实现具体榫卯模型和玩法。当前没有远端仓库；旧项目备份库不作为本项目远端。
