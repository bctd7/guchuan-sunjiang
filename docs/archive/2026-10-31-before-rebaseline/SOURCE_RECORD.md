# 《古船榫匠》—— 古代木船榫卯结构互动游戏策划

## 一、游戏定位

**游戏名称**：古船榫匠
**受众**：儿童（7 岁 +）、成人，亲子共玩；科普向 + 动手益智，兼顾历史文化、木工知识、空间逻辑。
**核心主题**：还原中国古代木帆船（福船）的榫卯造船技艺，不靠钉子，只用榫卯咬合搭建古船，了解古代造船智慧。
**核心玩法**：选取船身零件，识别榫头、榫槽，匹配拼接，解决结构难题，完成不同阶段船只建造，解锁历史小故事。
**载体建议**：实体木质拼装教具 + 配套数字互动小程序（双版本，线下动手，线上辅助）

> 基础规则：所有构件无金属钉子，仅依靠榫卯咬合；拼接错误会出现 “松动预警”，船体漏水 / 变形，需要重新调整。

## 二、游戏世界观

古代闽地船坊，你是一名学徒，跟随老船匠学习建造福船。古代远洋木船完全依靠榫卯拼接木板、龙骨，每一处榫口都决定船只能不能下水、抗不抗风浪。你需要依次完成**船骨架搭建、船板合缝、船帆舾装**三大阶段，闯过 3 个以上场景，最终造出可以出海的古船。过程中穿插航海、海贸、海防的简短历史科普。

## 三、三大核心场景（可拓展第 4 个隐藏场景）

### 场景 1：船坞工坊・龙骨立架（基础入门场景，适合儿童上手）

✅ **场景背景**：临水木船作坊，地上摆放原木料、斧凿墨线，老船匠教你搭建船的 “脊梁”—— 龙骨。
✅ **搭建目标**：拼出福船龙骨、肋骨框架。
✅ **榫卯类型**：燕尾榫、半榫、透榫
✅ **游戏任务**

1. 识别龙骨长料，将肋骨（船肋）通过半榫卡入龙骨预留槽位；
2. 左右对称安装船肋，必须两边榫口全部咬合，框架才不会倾倒；
3. 小挑战：如果榫头长短选错，框架倾斜，提示 “骨架歪斜，不能铺船板”。
✅ **科普知识点**：龙骨是船的主梁，古代造船先立龙骨；福船多层船肋支撑船体。
✅ **难度**：低，亲子协作，儿童负责对齐榫口，成人辅助识别零件。

### 场景 2：滩头船台・船板合壳（进阶场景，成人重点参与）

✅ **场景背景**：海边滩头船台，龙骨骨架已经立好，需要一块块拼装外船板，拼出船壳。
✅ **搭建目标**：拼接船身外壳，完成板与板之间的搭接榫。
✅ **榫卯类型**：搭扣榫、企口榫、扣合榫
✅ **游戏任务**

1. 船板之间使用企口榫互相咬合，像拼木板墙，依次从船底向船舷向上铺板；
2. 难点：**错缝拼接**，上下两层船板接缝不能对齐，否则船体容易开裂；
3. 压力测试关卡：拼装完成后模拟海浪冲击，若榫卯未卡紧，船板会 “漏水”（小程序可视化漏水动画 / 实体模型可以轻微晃动测试），需要重新调整；
✅ **科普知识点**：古船水密隔舱！完成船壳后解锁水密隔舱榫卯结构，隔舱就算一处破损，船也不会沉没，是中国古代造船伟大发明。
✅ **难度**：中等，需要规划拼接顺序，适合成人思考布局，儿童负责摆放船板。

### 场景 3：港湾码头・帆樯舾装（综合闯关场景，成人 + 儿童配合解谜）

✅ **场景背景**：船体完工，停靠在港湾码头，安装桅杆、船舵、船帆、横木。
✅ **搭建目标**：桅杆、舵杆、帆索支撑结构榫卯组装。
✅ **榫卯类型**：粽角榫、夹头榫、穿榫
✅ **游戏任务**

1. 将桅杆底座用夹头榫固定在龙骨上，底座榫卯没有卡牢，桅杆会倾倒；
2. 安装舵：舵杆通过穿榫连接船尾，需要调整角度，保证舵可以转动；
3. 解谜任务：帆桁（支撑船帆的横木）和桅杆使用粽角榫固定，要考虑受力方向；
4. 最终下水测试：全部拼装完成，船只可平稳浮在水面（实体版可浅水漂浮测试）。
✅ **科普知识点**：古代帆船桅杆固定工艺，福船尾舵技术。
✅ **难度**：偏高，需要理解受力，适合成人规划，儿童安装小件。

### 隐藏场景 4：深海风浪试炼（解锁场景）

通关前 3 个场景解锁。模拟远洋风浪，玩家需要检查全船所有榫卯节点，找到松动榫口进行加固。如果关键榫卯断裂，船只破损，任务失败。科普：远洋海船对榫卯耐久的要求。

## 四、游戏玩法机制

1. **零件图鉴**：每个木构件标注名称，点击查看榫卯原理、古船历史。
2. **错误反馈**
   - 实体版：零件放错无法卡入；拼装不稳轻轻晃动就散架；
   - 数字小程序：动画展示 “船体变形、漏水、桅杆倒塌”。
3. **双人协作模式（推荐亲子）**
   - 儿童：负责挑选零件、对位、拼接；
   - 成人：负责规划搭建顺序、判断受力、解决复杂榫卯谜题。
4. **收集系统**：每完成一个场景解锁一张古船手绘卡片（福船、广船、鸟船等古代船型）。
5. **成就**：【龙骨匠人】【水密隔舱大师】【扬帆舵手】
