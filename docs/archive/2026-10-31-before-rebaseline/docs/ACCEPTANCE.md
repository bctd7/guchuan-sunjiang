# 当前验收操作

Godot 4.7.2 打开项目根目录 project.godot，F5 进入目录。三关可直接进入；本次重点修改第一关和共享教学页，第二关暂存修复未合入。

1. 开场三种模型已去掉灰方块。点任一“观察此榫卯”进入原课堂；返回介绍后点“开始本关”。三关各三种，独立原课堂仍有九种。
2. 第一关龙骨已摆好，顶部写当前任务。点“进入观察与选材”，先看真实榫头形状，再比右侧槽位和三根同尺度长度。榫型和木料 A/B/C 必须自己选择，初始无默认。可拖动旋转、“看孔内”、重新观察；右上“本关榫卯讲解”可重访原课堂。
3. 返回后点船体圆点。榫型错会拒绝；短、合适、长均可试装。每种连接亲手做一处，其余七件继续逐件自动插入，不改变此前约定的重复规则。
4. 依次完成船肋半榫、龙骨燕尾、横梁透榫。全部装齐且动画结束后点“检查稳定”。故意用错长度，应看到构件仍装在架上但松动，文字指出问题连接。点“撤回上一组”换木料；有后续承托件时先撤后装的组。修正后再次检查，应成功并显示局部俯视图。
5. 主场景“船匠的小故事”自由阅读，可随时关闭或Esc返回，不改变进度或镜头。故事人物为情景创作，工艺事实依据官方非遗资料。
6. 第二关原玩法：观察真实槽口，从底向舷铺六块板，比较相邻排的板端短接缝；长水平企口接边无需错开。选择相邻排相同排布后装齐检查，应漏水失败，修复端缝后重排通关。第二关原展开图目前仍为参考示例；实时图修复暂未合入。
7. 第三关原玩法：桅座、帆桁、船尾三个局部工作台完成八件。舵轴先穿轴承，舵叶随后侧夹装。左右操舵均测试才完成；固定榫卯支架不随舵转动。

本轮详情见 tests/RESUMED_UI_VERIFICATION.md。测试为自动化事件与真实GPU画面核查，不等同人工或实体触屏验收。船体、长度、运动、水密均为教学设计，不是历史施工复原或实体工程认证。

# 三关验收操作

Godot 4.7.2 打开项目根目录的 project.godot，F5 进入关卡目录；三关均可直接进入。返回目录会保留本次运行进度，重新搭建只重置当前关。

1. 每关先显示本关三种榫卯的原模型图片；点“观察此榫卯”进入对应原课堂，返回介绍后点“开始本关”。关内也可回看，进度不变。第一关为燕尾榫、半榫、透榫，第二关为搭扣榫、企口榫、扣合榫，第三关为粽角榫、夹头榫、穿榫。独立打开原课堂仍有九种，未移除教学内容。
2. 第一关：固定龙骨已摆好。从“观察并选择榫型”进入局部，拖动可限角旋转，“看孔内”看盲底/通孔。三种真实候选在选择前可见，不设长度选择。选好后返回，点船体目标。依次手动完成左船肋、龙骨燕尾端接、横梁透榫三种示范；每次局部演示结束返回，其他同类构件逐件自动插入，不计为手动操作。进度明确显示手动 3/3、自动 7/7；每件实际 Tween 结束才接下一件，全部结束才开放“检查稳定”。撤回会撤回整组；重新搭建保留固定基座。通关切到这一段骨架的俯视图。
3. 第一关主页面已删除“观察全架”和 01/02/03 编号，右上保留“返回关卡目录”。侧栏缩短、模型按可用区域构图；只有第一关使用降饱和、柔化、压低对比度的船坊背景，原图未改，木材几何和材质未改。
4. 第二关：六块船板组成三排，比较相邻排的板端短接缝，选择 A/B 排布；水平长接边不需错开。每件先观察真实槽口再选型。故意把相邻排端缝对齐，在装完后检测漏水，再“修复端缝”纠正。装齐搭扣、扣合支持及隔舱后检查。十件均实际插入，插入期间不能快速换件跳过，未装齐或运动中检查不可用；撤回和重置可取消当前动画。
5. 第三关：在桅座、帆桁、船尾三个局部工作台完成八件装配。每件先看下方真实候选；装入动画完成后才能继续。舵轴先穿轴承，分体舵叶从侧面夹装；装齐后分别向左、向右操舵。只有舵轴与舵叶旋转，固定榫卯支架不转。
6. 试选一次错误榫型、重复点击目标、动画中尝试换件/检查，以及撤回、重置、课堂往返、返回目录再进入。第一关自动构件不会变成额外强制手动步骤。

本轮验证为自动化输入/状态测试和真实 GPU 截图检查，未在用户前台做人工完整试玩，未使用实体触屏。船体、运动和水密展示为教学设计，不是历史考证或实体工程验证。
