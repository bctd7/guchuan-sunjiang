# 第一关 r7：自动失败与重新开始

2026-10-31。运行日志版本为 `automatic-failure-20261031-r7`，入口仍为 `campaign/campaign.tscn`。本记录覆盖 r6 和迁移基线中“装齐后手动检查才晃动、可以撤回纠正”的规则。

## 当前流程

- 未选择、点错目标、浅推或往回抽出不算失败；这些操作尚未形成接合。
- 三种榫型、三档长度仍可试装。错误选择实际装入并结束展示后，自动晃动并弹出“拼接有错误哦”，下面提供“重新开始”。无需装齐，也无需点“检查稳定”。错误代表件不会继续复制到同类自动件。
- 失败后本关未通过，不能撤回、换件、重检或继续装配；Esc 不能关掉失败弹窗。可以返回目录，再进本关仍保持失败，直到重新开始。
- “重新开始”取消当前插入和晃动以及待执行回调，清空本关选择、进度和完成标记，保留固定龙骨。其他关卡的实例、进度和完成标记保留。
- 正确示范仍需三次手动、七件逐一自动补齐；动画全部结束后手动“检查稳定”通过。未失败时，正确构件的成组撤回和重新搭建仍可用。
- 木料上的“沿槽口推入 / 松手接好”悬浮文字已移除，方向箭头、木料拾取、沿路径推进、续拖和抽回不变。

## 验收步骤

1. 进入第一关并开始。选择错误榫型或短/长木料，实际拖入后松手；不点“检查稳定”，应自动晃动并显示失败弹窗。
2. 分别在船肋、龙骨端接、横梁试错。试错时提前关闭观察页，仍须等真实装入结束才触发失败，不应开始后续自动装配。
3. 失败后尝试 Esc、重复点击、撤回、检查、故事入口；均不能恢复当前失败挑战。返回目录再进入，失败弹窗保持。
4. 点弹窗“重新开始”。确认固定龙骨保留、榫型和长度重新选择；在晃动期间重开也应安全，不出现稍后弹回的失败提示或自动构件。
5. 重新选三处正确榫型与合适长度，观察三次示范与七件自动补齐，最后检查通过；课堂往返正常。
6. 先在其他关保留部分进度或通关，再让第一关失败并重开；其他关的进度和标记应保留。

## 实现边界

状态层在可见接合完成时评估配合，区分未装齐、错误接合、失败和通关。协调器等待船架及当前可见局部展示的实际结束信号；提前关闭局部展示时仍等待船架插入结束。取消与重开增加动画代次，旧回调无法影响新挑战中同名代表件。

本轮不修改第二、三关玩法、原始模型、镜头参数或关卡存档机制。进度仍仅保留在本次应用运行中。
