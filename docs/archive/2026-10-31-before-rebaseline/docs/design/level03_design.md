# 第三关：帆樯舾装

三个真实船件局部工作台连续完成，不展示全船。此布置是教学假设，不宣称古船原位复原。二维结构图 `level03_structure.png` 是开工前结构核验依据。

1. 桅座框：固定大边；抹头沿 -Z 与大边 45° 肩互接；带长短榫和三向斜肩的角腿由下向上装；框接完成后桅杆方脚落入桅座。粽角的配合几何沿用已核验定义并延展为船件，不摆独立教学实例。
2. 桅顶帆桁夹座：叉口是桅杆顶端本体；牙条先落入叉口；带帆桁的承托板再向下套住顶端双榫。双槽是真实空腔且保留封底。
3. 船尾舵架：较大后段与较小前端组成阶梯 L 型穿榫，横撑沿 -X 通过阶梯槽固定舵架。横撑承载独立圆轴承。先将**无叶直圆轴**从上向下穿过圆孔，顶端止推肩留在孔上承重；然后从船外侧将舵叶的半夹套向轴脚平移，合上另一半夹套并固定销。夹套/销是可拆机械连接，明确不属于本关三种榫卯。带宽叶木件不穿圆孔。轴径 0.34，轴承孔径 0.40，径向间隙 0.03；游戏角度 ±30°。固定榫卯件绝不随舵叶转动。

桅座框装配时只显示架空框和侧边支承，不生成跨过角腿装入路径的甲板；角腿从下方空处上装。轴孔沿 Y 贯通，横撑环绕轴承留空，任何木方不会封住轴孔。

## 分层与流程

规则定义依赖顺序与候选类型；状态只接受有效意图并记录撤回历史；视图只构造几何和动画；独立交互层接收 Viewport 鼠标/触屏；奶油色界面复用已有主题。根场景 Node3D 暴露 `state/view/panel` 和 `level_completed/return_requested`。

初始不默认选榫。三个真实候选端部先可见，点击候选后局部船件换成对应榫头；错误类型点槽后拒装且不增加进度。粽角步骤候选呈现长短榫；夹头步骤呈现叉口/牙条/双榫；L 穿榫与普通直透榫的形状清楚区分。撤回允许试装重做；重置回第一步。完成全部安装后必须左、右实测圆舵轴才触发完成。

## 验收

运行静态规则、几何间隙及依赖测试，再通过真实 Viewport 鼠标/触屏输入依次验证错误、正确、重复、撤回、重试、全关完成。保存三工作台、槽口/候选、左右舵角截图和 JSON 报告。控制台日志保存到工作区 evidence/level03*.log。
