# 第一关：观察、试装与调整

## 玩家操作

1. 点“看榫头，挑木料”。上方整张榫型卡片（含模型图）均可选择；侧边选择木料 A/B/C。未明确选择两项时不会替玩家决定。
2. 按住木料实体或标出的可抓小圆环，木料跟随鼠标/手指自由移动。把榫头或所抓位置拖到发亮入口圈内，出现“松手试装”后释放，自动完成插入；空白处仍旋转。
3. 三种榫型和各档长度都能试装。正确配合接稳；不合适的榫型或长度会在接触后晃动。
4. 点“取回调整”重新选材；也可继续搭建，观察其余同类构件依次装配。自动件保留实际所选榫型和长度，不会换成正确答案。
5. 全部装配动画结束后检查稳定。松动组显示“待调整”，不会通关。调整较早的船肋时，先撤回后装的横梁组，再撤回原组；龙骨基座始终保留。

## 实现边界

- 规则和状态分开记录“已试装”和“配合正确”；未知输入、错误目标位置、重复安装和支撑顺序仍受约束。
- `trial_fit.gd` 管理视觉装配位置和运动方向。错误榫型也进入装配位置，然后晃动；内部相交由不透明槽体遮挡，所选榫型和长度的网格、记录均保留，不把错件替换成正确模型。
- 船架视图保存原始木料基线，实际场景和观察页都使用所选榫型、长度。候选预览从基线复制，不污染正式木料或其他候选。
- 观察页负责选材、试装回放和取回入口；控制器负责状态、自动队列及撤回。r3移除了隐藏的轨迹百分比和行程上限，释放范围就是画面中的入口圈，按显示尺寸适配；允许非直线拖动及适度越过入口。点击不安装，失焦、取消触摸、多指和界面外释放仍保护状态。未命中会解释原因。
- 暖木风格、第一关背景、三次代表操作与七件自动装配、九种课堂保持；第二三关暂存修改不合入。

## 验证与限制

- 规则覆盖三处目标的三种榫型×三种长度、组合装配、自动继承、重复、撤回、重置和通关；几何覆盖安全接触、实体槽壁和基线恢复。
- r3程序检查：三个连接位各三种榫型×三档长度，共27组；每组记录拖入、稳定或松动反馈、取回清空选择，最后正确重建通关。后台GPU/GUI事件515项通过、0失败；自由拖动、半分辨率渲染、偏移/缩放、斜向、越过入口、快速释放、失焦及取消保护20项通过、0失败；旋转55/0。记录和截图在 `tests/evidence/dropzone-r3/`。
