# 第一关：沿轨迹试装（r5）

启动方式不变：关卡目录 → 第一关 → 开始本关 → 进入观察与选材。
先选榫型与木料；按住木料本体或旁边的小抓取环，沿箭头推进。
构件沿实际插入方向移动，反向拖动可抽出。浅推松手会停在当前位置，
可以重新抓住继续推；推入足够深时显示“松手接好”，松手后完成短吸附。
不再要求把鼠标或构件拖到某个接收圆圈。拖空白处仍用于旋转观察。

所有已知榫型和长度都允许试装。正确榫型与长度稳定，其他组合装入后
显示松动，可“取回调整”重选。选择、长度、正确答案及自动补齐规则没有改变。
错误榫型试装时仅调整观察页克隆件的局部接收空间，避免榫头穿入接收木料；
取回或完全抽出后恢复原槽口，原始船体与课堂模型不受影响。

“船匠的小故事”入口保留，内容改为“龙骨里的七星伴月”，配轻量木纹、
铜镜和七枚钱币排列示意。故事可随时关闭，不改变装配状态。

代码分工：
- `assembly_drag_surface.gd`：拾取、手势锁定、沿路径推进/抽出及松手深度。
- `joint_inspector.gd`：观察页、选择、短吸附动画和展示状态协调。
- `trial_receiver.gd`：仅克隆件的局部接收空间及还原。
- `connection_rules.gd` / `level_state.gd`：既有选择记录与稳定规则。
- `shipwright_story.gd` / `seven_stars_illustration.gd`：可选故事与示意。

验证：27 组（3 连接位 × 3 榫型 × 3 长度）通过实际 GPU + Viewport
鼠标/触摸事件验证，包含推进、回拉、浅推续拖、试装反馈、取回和正确通关。
这是程序交互验证，不等同于原生鼠标或实体触屏验收。
上一版 r3 的 27 组真实鼠标记录不能作为 r5 的真实鼠标验证。
本版没有重新接管用户桌面；原生鼠标和实体触屏仍待复测。
