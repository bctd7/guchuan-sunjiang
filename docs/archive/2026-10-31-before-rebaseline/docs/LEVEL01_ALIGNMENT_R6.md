# 第一关 r6：故事卡与接合展示

启动仍为关卡目录 → 第一关 → 开始本关。更新后请重新运行项目，
本版日志标识为 `alignment-section-20261028-r6`。

## 玩家可见变化

- 木料上的抓取圆环已移除。按住木料本体，沿箭头推进或往回抽出；
  浅推松手后仍可续拖，深入后松手接好。空白拖动继续旋转观察。
- 第二、三处松手时保留镜头，装入后平滑移至接合处，避免突然换构图
  被误解为木料跳位。第一处船肋的模型与观察方式保留。
- 燕尾端接及横撑的“看孔内”使用不透明的局部剖开，避免半透明木面
  叠在榫头上造成穿插观感。回看/关闭剖面会还原克隆模型。
- 错榫型的接收空间适配榫头的完整进入路径。横撑的头部先经过右侧孔，
  再到左侧孔，两处都覆盖；长榫回放起点按实际榫头保证在孔外。
- 故事入口保留。卡片改为上图下文，丰富工作台、木纹、铜镜、七枚钱币
  及轻量工具环境；正文局部常规字重，标题与注记层级分明。
  小视口可滚动阅读全文，关闭按钮固定可见。

## 规则未改

三种榫型和三档长度都能试装。只有当前连接要求的榫型及正确长度稳定；
错误组合装入后松动，可以取回调整。长料留肩口缝是错误长度的反馈，
不能当成正确闭合。没有改拼接次数、自动补齐、其他关卡或九种课堂内容。

## 本轮排查与验证

1. 最终位置的27组几何诊断未发现接收木料体积内的相交。
2. 增加途中采样后，查到横撑错用燕尾榫时会先碰右侧孔壁；此前只适配
   最终位置。改为覆盖整个榫头行进包络后，27组最终位置及9个途中
   采样位置均未再报可见模型相交。诊断排除了实际运动时隐藏的木销。
3. 真实GPU渲染与Viewport鼠标/触摸事件覆盖27组选择、推进、拉回、续拖、
   取回及纠正通关；导出途中、正面、侧面、背面和孔内图片，并检查
   松手瞬间不换镜头。报告及图片在 `tests/evidence/alignment-r6-verified/`。
4. 可选故事入口、关闭、焦点恢复及两种视口渲染单独回归。

这些是程序交互、网格诊断与渲染复核，不能替代原生鼠标或实体触屏验收。
没有宣称微小、不可见接触或任意角度绝对无相交；真实输入尚待复测。
原始船体资源不变，适配与剖切只作用于观察页克隆件。
