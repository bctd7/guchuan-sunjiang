# 第一关：龙骨立架（当前流程）

默认 F5 进入三关目录，从目录进入 `res://levels/level01/level01.tscn`。龙骨已固定，不再让玩家选唯一长料、点击唯一基座。

玩家只做三次有实质区别的操作：

1. 左船肋半榫从侧面进入有底盲槽；返回主画面后自动补齐另外五根船肋，保持三对左右对称。
2. 前延长段燕尾从开放端沿纵向滑入；自动补齐镜像方向的后延长段。
3. 前横撑以等截面穿过两侧船肋通孔，两端露出；自动补齐另一站位横撑。

每次从唯一“观察并选择榫型”入口看实际部件；三种候选同时可见，初始不默认选择。鼠标拖动或单指可限角旋转；“看孔内”只透视接收件，当前榫头保持不透明，半榫真实槽底保留可见。主页面没有第二套构件/榫型/木料选择。

所有类型统一暂缓长度选择和长短挑战，按固定接合尺寸装入；保留的旧长度比较源码不再加载，不能把旧 A/B/C 验收说明当作现行玩法。错误榫型仍明确拒绝，观察或切换候选不会放入木料。

手动进度 0/3 与自动补齐 0/7 分开显示；固定龙骨不计入操作。自动动画只在手动示范之后、关闭观察返回主画面后开始，不能伪装为玩家动作。自动补齐期间禁止新示范和验收，可撤回或重置取消；撤回整组，不留下半个左右对称结构。全部 11 个实体正确就位后仍需“检查稳定”，成功后可收起卡片看船体局部俯视。

`connection_rules.gd` 负责连接与分组；`level_state.gd` 负责来源、历史、状态；`ship_geometry.gd` 负责实际木件；`skeleton_view.gd` 负责场景、目标与动画；`joint_inspector.gd` 负责真实部件的局部观察；`level_ui.gd` 负责主页面展示；`level01.gd` 负责协调。输入共用 `levels/shared/socket_interaction.gd`。

半榫为盲直榫而非搭扣榫；榫卯在船件上的布置属于教学设计，不是古船历史定论。九种原课堂资源保持原样，往返保留本次关卡状态。

当前验证与证据见 [LEVEL01_CURRENT_VERIFICATION](../../../../../tests/LEVEL01_CURRENT_VERIFICATION.md)。鼠标/触摸由 Viewport 自动注入验证；后台 GPU 截图使用独立离屏 SubViewport 和隐藏 NO_FOCUS 宿主，不代表真人手动或实体触屏验收。
