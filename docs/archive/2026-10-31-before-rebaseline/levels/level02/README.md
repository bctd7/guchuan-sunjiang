# 第二关：船板合壳

入口 `res://levels/level02/level02.tscn`；`extends Node3D`；public `state/view/panel`。导航信号 `level_completed`（验收成功）和 `return_requested`（目录、成功后继续）。只读复用第一关 `touch_interaction.gd` 与共享奶油木色主题。

玩家逐件选择、放大实际船材槽口、对照三种可动候选几何、选择榫型，返回船壳后点圆点。三列各两板由底向舷铺设；底列端缝 X=-1.40，中/舷列排布 A=-1.40 或 B=+1.40。同列两板沿用同一排布。正确示例 A/B/A；长水平拼边不计为端缝。对齐可试装，验收会显示红色端缝和水滴；“修正端缝”撤回首个错误板列及后续构件。共十次有意义放置。

真实船材均在 `ship_geometry.gd` 新造，无旧教学 OBJ。企口为连续直舌/槽；舌厚 .06、深 .09，槽厚 .07、深 .10，板厚 .18、列宽 .78。十字框两材各刻半，位于 X=-2.8、Y=1.25，总厚 .24；构件长 1.86。三向横撑位于 X=+2.5、Y=1.25，三根水平材在 XZ 平面 0°/±60°，长 2.0，交叠处按底/中/顶三层裁切；每层 .08，中撑后顶撑沿 -Y 落入。端部留在两侧船壳内表面以内，固定支脚接到底板。曲肋和预建远侧船壳提供局部船段上下文；可操作板带是近似平直舷侧。

隔舱最后安装在 X=0；底轨中心 Y=.285，底面 .165 与底板顶面贴合。两侧斜边按厚 .18 壳板内表面计算，留 .003 教学装配缝。验收成功后显示真实密封条和左舱浅水示意。木榫本身不保证水密；这是教学组合，不是历史原位、强度或真实流体模拟结论，实际仍需填缝、密封、材料工艺检查与实体试水。

文件分层：`connection_rules.gd` 规则；`level_state.gd` 状态；`hull_view.gd` 视图/动画；`ship_geometry.gd` 静态几何；`joint_gallery.gd` 三候选预览；`level_ui.gd` UI；`level02.gd` 协调。二维图与方案在 `docs/design/level02-*`。

验证：`tests/level02_rules_tests.gd`（规则），`tests/level02_geometry_tests.gd`（真实 BoxMesh 插入、三向裁剪体积、船壳内壁余量、实际隔舱三角面穿越），`tests/level02_input_tests.gd`（真实 Viewport 鼠标/触摸，错误、重试、修正、通关、重置及动画中撤回）。报告 `tests/level02_*_report.json`；截图 `tests/level02_evidence/`。静态路径检查包含正例与反向插入碰撞负例；隔舱用 1,240 条沿 X 采样射线检查封断，仅代表当前教学尺度静态几何采样。
