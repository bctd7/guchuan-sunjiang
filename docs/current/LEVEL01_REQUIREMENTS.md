# 第一关需求：船坞工坊·龙骨立架

更新：2026-10-31。[共同范围与来源](README.md) / [实际技术架构](TECHNICAL_ARCHITECTURE.md)。本文件的“目标”是用户最新要求，“现状”是已有实现；未定参数不自行设值。

## 1. 背景、目标与学习重点

场景为临水的古代闽地木船作坊。玩家作为学徒，跟随老船匠搭建福船的龙骨与肋骨。背景可用贴图，地上摆原木、斧凿、墨线等少量陈设；本关突出木件和榫口可辨认，不要求完整复杂作坊。

目标是认识并配出**燕尾榫、半榫、透榫**，选对后逐步形成龙骨肋骨框架。学习重点是从多个材料中识别，不应只给唯一能合上的两个零件。选对后的对位可以由系统动画完成，避免把精密拖动当作核心难度。

| 结构 | 书面任务/科普意图 | 需求边界 |
|---|---|---|
| 燕尾榫 | 认识榫头与榫槽的形状、正确配合 | 具体船上位置为教学设计，不宣称原位考古复原 |
| 半榫 | 船肋进入龙骨预留槽，左右对称支撑 | 当前教材为有底盲直榫，不和搭扣十字刻半混淆 |
| 透榫 | 认识贯通孔与穿出端的配合 | 必须可看懂与半榫槽底的差别 |

## 2. 课程、候选材料与难度

进入关卡先介绍本关目标和三种结构，可观察榫头、槽口、组装前后。随后把目标件与干扰件放在可比较的材料区，玩家自己选出能匹配的结构；可复用其他榫卯教材部件作干扰。正确件、干扰件都应能看清几何，不只依赖文字标签代答。

第一关干扰最少，后续逐关增加。本轮谈话提过 4 选 3、6 选 3、9 选 3，以及九种对应十八块材料，均为讨论方案；最终候选种数、块数、是否按成对木件呈现未定。不能把三档长度直接称为已完成跨类型干扰设计。

零件图鉴可点击看名称和原理。亲子分工为儿童识别、选择与摆放，成人辅助观察和理解；不等同双账号、联机或强制双人操作。

## 3. 目标流程与输入

1. 进入作坊，看到待搭骨架和简短任务：“找出本关需要的三种榫卯”。
2. 学习/观察三种结构，可回看；课堂只用于认知，不替玩家完成正式选择。
3. 在混合材料中选择榫头与匹配槽件，提交匹配意图；是否一次选三组或逐组选择待定。
4. 对正确组合播放自动对齐、接合动画；相应船件进入骨架，玩家能区分自己识别的步骤和系统重复补齐。
5. 展示左右支撑和整体骨架形成，给出成功反馈与简短科普，进入下一阶段。

已确定需要选择、匹配和可见接合；点击、拖动、单指等具体提交方式沿目标机器再定。已有鼠标/触摸适配不等于实体机器已通过。若保留自由观察，旋转/观察输入不得误触成放置。

## 4. 成功、错误与重试

成功应来自选对三种结构并正确配合，展示骨架稳定和左右支撑，不能仅以动画结束或点击次数宣告学习完成。

口头要求选错不能正确咬合，给出失败/再试提示；书面还举榫头长短错误使骨架倾斜、“不能铺船板”的挑战。长短挑战的本次优先级需明确，不能让它取代形状识别。

失败时机存在冲突：本轮口头倾向选错即反馈，既有 r8 实现是整关装齐后统一失败；“原地换件重试”或“本关重新开始”的适用条件也未统一。先记录冲突，不能把旧 r8 或口头一句推测直接定为最终全关规则。任何失败反馈应说明错在何处，并保留清楚的下一步操作。

## 5. 模型、动画、界面与科普

- 材料区展示真实可辨榫端/槽形，选中态清楚；观察和正式选择区分。
- 正确时对齐并咬合，骨架逐步出现；自动补齐不伪装成玩家逐件完成。
- 错误可用对不齐、不能卡入或明显不稳表现；具体采用哪种须和最终失败时机一致。
- 成功展示一段清楚的龙骨/肋骨框架；完整船体和局部镜头如何切换尚待设计。
- 科普：龙骨如船的脊梁，先立龙骨，船肋支撑船体；不把简化教学布置说成所有古船统一构造。
- 书面通关收集古船卡片与【龙骨匠人】成就仍保留，展示方式和本次优先级待排。

## 6. 当前实现与差距

## 7. 边界条件与待确认

| 事项 | 必须明确的条件 |
|---|---|
| 候选池 | 总数、成对/单件、干扰类型、是否重排、名称可见策略 |
| 正式选择 | 一次选三组或逐组配对，是否允许未提交前取消 |
| 重复装配 | 每种手动次数、自动补齐范围及进度表达；谈话“每种两遍”非定案 |
| 失败/长度 | 即时/整关，拒装/装错，原地修正/重开；长短挑战是否保留 |
| 状态恢复 | 课堂、目录、失败和动画途中返回的明确规则；不影响其他关 |
| 触控体验 | 目标设备、手指目标尺寸、拖动阈值、观察/放置互斥；不得以自动事件替代实机 |

输入未选择、只选一半、重复提交、动画中提交、返回后旧动画回调、重新开始和成功后重入，都应有一致处理且不误增进度；这是后续验证边界，不宣称本轮已逐项运行。
