## 1. 场景、目标与榫卯

场景为海边滩头船台，龙骨肋骨已经立好，玩家逐层拼外船板形成船壳。背景可贴图，已有骨架提供建造上下文；重点展示板端、上下层位置和接缝，不让装饰遮挡。

| 目标结构 | 学习内容 | 表现要求 |
|---|---|---|
| 搭扣榫 | 辨认对应搭接形状并配对 | 与第一关半榫、其他干扰件可区分 |
| 企口榫 | 板边连续舌槽相互咬合，从船底向船舷铺 | 舌槽接边和板端短缝能分清 |
| 扣合榫 | 辨认本关教材使用的扣合结构 | 名称和选用模型一致，不借名称假定所有变体等同 |

本关完成船身外壳，并以可见后果理解错缝。板数、结构尺寸及支撑放置是教学参数，不能从旧十件实现直接提升为新需求定案。

## 2. 课程、干扰与输入

先学习本关三种结构，观察榫头/槽口；随后在混合材料中选出搭扣、企口、扣合。干扰应比第一关更多，可用其他部件；具体数量未定，6 选 3 只是谈话举例。所有正确/干扰材料形状清楚、可比较，选对后的动画辅助对齐。

玩家还必须能主动选择板端排布，而不只是看预制正确图。可采用点击排布或拖放等方式，输入形式沿目标机器决定。需要可回看错缝说明和观察局部，不用真实物理流体或精细三维操作才能理解。

## 3. “不能对齐”的准确含义

这里指**上下相邻板层的板端短接缝应错开**：不能连续几层都落在同一竖向位置。长水平企口接边仍需正确对接，不应误判为必须错开的线。

```text
端缝对齐：上层 ───│───   连续薄弱线（错误示意）
          下层 ───│───

端缝错开：上层 ─│─────   端缝位置不同（正确示意）
          下层 ─────│─
```

图示仅解释板端位置，不代表比例、实际施工尺寸或精确力学结论。界面必须能区分“当前玩家的接缝”和“参考示例”，不能用固定正确图冒充玩家实际排布。可通过标线/局部展开辅助识别，具体表现形式待设计。

## 4. 目标流程

1. 展示上一阶段骨架和铺板目标，学习三种榫卯及板端短缝含义。
2. 从含干扰的材料中选出并匹配三种结构，正确后演示接合。
3. 从船底向船舷铺板，玩家为相邻板层选择端缝布局；相同层内的板片须合理相接。
4. 视图随实际排布更新，让玩家看见连续对齐或错开的端缝。
5. 执行海浪冲击/压力测试；卡紧且排布正确的船壳稳定，错误有漏水或开裂动画。
6. 成功后解释水密隔舱与填缝密封，形成完整本阶段成果；按确认范围发卡片/成就并进入帆樯阶段。

书面要求压力测试；口头允许用简单小动画/视频表现漏水，表明无需工程仿真。是否错误排布立即演示，或等装齐后统一测试，仍须明确。

## 5. 成功、失败与表现

成功须同时包含目标榫卯正确、接合卡紧、相邻层板端错缝及完成测试。只选对材料不能代替错缝判断；只采用正确预设排布不能证明玩家理解。

错误分两类：选错结构导致不能正确咬合；船板已能接上但端缝上下对齐，形成开裂/漏水风险。后者必须有可见因果，不能只弹一句“失败”。未卡紧也应按书面测试表现后果，具体判断方式尚待设计。

反馈要指向相应板层或端缝，显示开裂、水进入等短动画；波浪冲击与结构后果保持先后可理解。失败后是原地更换/重排还是整关重来、何时锁输入，须统一。当前代码整关失败后重开不等于最新讨论已定案。

## 6. 科普与收集

解释企口等接边配合、错缝与连续薄弱线的区别；说明水密隔舱分隔舱位、帮助限制进水范围。榫卯不能单独保证水密，仍需填缝、艌密等工艺；避免“只要一处破损也绝不会沉没”的绝对表述。

儿童负责识别和摆放，成人辅助理解顺序与错缝；这是合作建议，不要求联机。通关手绘古船卡与【水密隔舱大师】成就保留为书面目标，具体本期安排待排定。

## 7. 当前实现与差距

已有十件顺序装配、三层各两板、A/B 实际排布；底列固定 A，相邻排短端缝错开才能通过。开场三种介绍及原课堂保留；每件必须观察、选榫，再抓住实际船材沿槽口方向推入。浅推松手保留进度，重新抓取可继续或拉回；达到吸附深度后松手只补完剩余入位动画。错误榫型仍拒装。

`seam_diagram.gd` 实时展示已装、未装及当前 A/B 预览，替代正式 UI 对固定 `seam_reference.png` 的加载。旧图片保留作历史素材，不再显示过时“可撤回修正”。十件全部真实入位后自动试浪：浪峰接近、冲击、退去；对齐短端缝显示裂缝与移动水滴，正确组合不显示漏水。试浪结束才统一调用状态验收；失败锁定，只能重开或回目录。试浪中重开/撤回会取消旧动效与回调。

第二关独立滩头船台背景采用淡化木色矢量插画，不改船材几何与材质。隔舱小课堂提供分舱限流示意、艌密说明及实体试水边界，关闭恢复输入和焦点，不改进度。UI/镜头适配 1440×900、1100×800、960×600 的验证视口。

保留差距：扩大的混合候选池、递增干扰、收集卡/成就未做；本次按确认保留三种介绍。松手未到深度的木料不会记为已安装，因此没有独立“未卡紧也计装好”的玩法；海浪、水滴和裂缝是教学表现，不是工程求解。真人鼠标、触控板、实体触屏及最终目标机器验收仍需执行。
