# 音乐与落座音效

统一入口 `shared/game_audio.gd`（GameAudio Autoload），场景调用 `shared/seating_audio.gd`。没有触摸设置面板，不改变原导航、拼装或判定。

## 默认与维护

Music 总线 -19dB，SFX 总线 -9dB；音乐 2.5 秒淡入。源配乐约 -16.1dBFS RMS，默认混音约 -35.1dBFS RMS；木声源峰值约 -6.37dBFS，默认峰值约 -15.37dBFS。环境响度还受系统音量与扬声器影响，不能以 dBFS 推断现场声压。

外接维护键盘按住 Ctrl+Shift：
- F5 / F6：音乐降低 / 增加 2dB。
- F7 / F8：音效降低 / 增加 2dB。
- F9：音乐静音切换。
- F10：音效静音切换。

与已有 F11、Q 维护键不冲突。设置保存到 Godot `user://audio.cfg`；可编辑 `[Music]`、`[SFX]` 的 `volume_db`（-60 至 0）与 `muted`（true/false），下次启动读取。也可调用 `GameAudio.configure("Music", -19, false)`。无设备或资源缺失时不阻断游戏。只有一个音乐播放器，不随目录、讲解、观察切换重新创建。

## 触发边界

- 第一关：可见观察模型插入到位时播放一次；主船对应的同步动画静音。自动补齐由 skeleton_view 的实际变换动画结束处触发。预览/重新播放介绍不发声。
- 第二关：只在成功落座动画的 generation 校验后播放；包括手动、中件和自动补齐。`_animate_contact_stop` 受阻分支不播放。发声在整关正确性判定前，因此真实落座的错误材料有同样物理音效。
- 第三关：rigging_view 实际装入 Tween 最后回调触发，舵叶等双部件动作全部就位后一次。
- 不建立延迟音效队列；单音效播放器限制叠加，总线独立。取消动画会取消绑定回调，generation 排除旧操作；离树时停止所属音效。资源读取仅发生在启动。

来源、原创合成及授权记录：[SOURCES](../../audio/SOURCES.md)。验证和限制：[验证报告](../../tests/AUDIO_VERIFICATION.md)。

## 补充操作反馈

所有动态创建的按钮统一监听实际 pressed 事件，复用 wood_seat 音色：普通点击/选材音高 1.5、额外 -13dB；撤回/取回 0.85；重新操作 0.95。成功面板出现播放 1.25 音高、额外 -5dB；失败面板出现播放 0.7 音高、额外 -5dB。这些数值均叠加 SFX 总线音量，统一受 SFX 静音控制。

独立单声道反馈播放器不截断落座声；落座声或反馈音播放期间跳过普通按钮声，连续普通操作另有 110ms 限频。成功/失败只在结果界面首次可见时响，重复刷新不再响。无新增音频文件、延迟音序列或玩法判定。浅推、抽回、旋转与连续缩放不新增过程声；撤回/重开现在有轻量操作反馈，但仍不播放落座声。

操作反馈已改用 ui_tap.wav（65ms，12ms 尾部淡出）：点击约43ms、撤回76ms、重开68ms、成功52ms、失败93ms。原落座声保持240ms。
