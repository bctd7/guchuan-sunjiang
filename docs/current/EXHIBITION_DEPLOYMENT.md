# 32 寸横屏展览部署

本次目标：1920×1080，16:9，32 寸触摸屏。未修改操作系统设置，游戏规则、音乐、拼音、视频与引导流程未改动。

## 布局与输入

工程设计视口及窗口尺寸改为 1920×1080，默认普通全屏（Godot MODE_FULLSCREEN=3）。`canvas_items` 配合 `keep` 保持设计宽高比，其他比例屏幕允许留边，不能据此认定系统被锁定。

保留原船坊 1440×900 内部排版，用共享 `exhibition_layout.gd` 等比映射到新设计画布；目标设备上缩放 1.2 倍，内容区 1728×1080，左右各留 96 像素安全区。目录背景与三维背景覆盖画布。介绍卡、独立课堂和科普页继续沿用容器/锚点布局。第一关模型安全区和 UI 使用同一映射；第三关主模型在独立 SubViewport 中渲染，点击槽口使用实际容器变换，避免缩放后的命中偏移。

候选卡有意显示接头近景；第一、二关“放大”查看完整木料。模型网格不作横纵不同比例缩放。默认课堂、总览和完整木料展示保持模型可见；主动缩放/旋转仍允许观察局部，使用“重置视角”恢复。

目标画面检查中的按钮短边至少 60 像素（32 寸 16:9 屏幕约 22 毫米），关闭科普按钮 64 像素，保留按钮间距。第二关进度入口从小字行移为页脚独立触摸按钮。第三关缩短候选预览以腾出按钮及页脚间距；操舵按钮保留间隔。鼠标、键盘、既有单指操作和双指缩放能力保留。实际触摸精度、阅读距离和儿童误触情况仍需现场确认。

## 维护人员操作

- 外接键盘 **Ctrl+Shift+F11**：全屏与窗口模式切换。窗口模式可用鼠标操作系统窗口；再按一次恢复全屏。部分键盘需同时按 Fn 产生 F11。
- 外接键盘 **Ctrl+Shift+Q**：直接退出游戏，不弹出触摸确认框。本工程没有跨运行存档，退出后本次进度不保留。
- **Esc**：沿用现有界面返回/关闭弹窗行为，不退出全屏。
- 切换应用使用设备系统允许的键盘方式，例如 Windows 的 Alt+Tab 或 macOS 的 Command+Tab；若系统 kiosk 策略禁用，使用现场配置的管理员维护通道。游戏不拦截系统快捷键。

游戏没有退出全屏、退出程序或切换应用的触摸入口。维护组合键是操作便利措施，不是权限认证；如需阻止公众接入键盘，应由设备部署管理控制。

## 最终设备仍需配置与验收

下列均**未在最终 32 寸设备验证，也未代为修改系统**：

1. 系统输出设为 1920×1080 横屏，确认主显示器、显示缩放、无 overscan/裁边、触摸坐标映射正确，导出程序启动在指定屏幕。
2. 按实际系统与版本配置展览/kiosk 账户及策略：边缘滑动、多指系统手势、任务栏/程序坞、通知中心、应用切换、虚拟桌面、热区和辅助功能入口。游戏全屏本身不提供这些限制。
3. 配置维护人员恢复入口、管理员凭据和外接键鼠路径；确认锁定策略下仍能退出维护，并确认恢复展览后策略生效。
4. 按展馆要求配置开机自动登录/启动、异常退出恢复、屏保、休眠、自动锁屏、更新与通知时段，完成断电重启演练。
5. 验证触控驱动、单指拖动、双指缩放、触摸产生的鼠标事件、快速重复点击、多指与外接鼠标交替；逐关装配、撤回、失败/成功、重开、课堂与目录往返。
6. 实机检查中文字形、显示亮度/反光、站立阅读距离、儿童触达范围、按钮误触和长期运行的帧率、温度、内存与稳定性。
7. 按目标系统导出正式发行包，验证资源/字体完整、图形驱动兼容、系统策略和应用权限。当前 Mac 编辑器/GPU 验证不代表 Windows/Linux 发行包或最终设备验收。
