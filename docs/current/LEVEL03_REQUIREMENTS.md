# 第三关需求：港湾码头·帆樯舾装

更新：2026-10-31。[共同范围与来源](README.md) / [实际技术架构](TECHNICAL_ARCHITECTURE.md)。本关需要识别选材，并增加固定、安装角度和受力判断；现有试舵演示只覆盖其中一部分。

## 1. 背景、成果与榫卯分配

船壳已完成，停靠港湾码头，玩家安装桅杆、舵、船帆及横木/支撑，最终看到古船可平稳下水。本关难度最高，成人辅助规划，儿童识别和安装；场景背景仍可贴图，不要求复杂港口建模。

| 书面目标榫卯 | 书面用途 | 当前代码用途 | 处理原则 |
|---|---|---|---|
| 夹头榫 | 桅杆底座固定在龙骨上 | 桅顶帆桁承托 | 书面/代码冲突待确认，不自行称已符合 |
| 粽角榫 | 帆桁与桅杆固定，考虑受力方向 | 桅座框 | 同上，需统一模型、文案、规则与科普 |
| 穿榫 | 船尾舵杆连接并保证能转动 | L 型穿榫固定舵架，独立圆轴与舵叶转动 | 属实现变体；确认是否符合书面意图，固定架与转动件应可区分 |

以上目标来自用户书面策划，不作历史原位或工程正确性背书。现有教材模型可以作基础，但不能以代码已存在倒推用户接受了相反用途。

## 2. 课程与递增干扰

先观察粽角、夹头、穿榫的接合形状、运动方向及固定/转动区别，再从比第二关更多的混合材料中找出本关三种。9 选 3 是讨论方案，最终种数、块数及相似干扰件未定。

三关均须重新面对混合候选，不应因为第一关用掉三种就从总材料池永久删去，让第三关只剩唯一答案。观察本身不自动计正式选对，候选名称、槽口与实际形状一致。

## 3. 目标流程和交互

1. 展示完成的船壳及本阶段待安装部分，介绍三种结构和风险。
2. 在混合材料中识别、选择并匹配本关三种连接。
3. 安装桅杆底座和桅杆，玩家判断是否卡牢；接合动画清楚展示固定条件。
4. 安装船尾舵杆/支架，玩家调整安装角度，使其既稳固又能转动。
5. 安装帆桁与桅杆连接，考虑受力方向；帆/帆索支撑呈现范围待明确。
6. 验证固定与转动：未卡牢出现倾倒；正确安装可左右操舵，固定支架不随舵一起转。
7. 完成后展示整船平稳下水/漂浮，给出简短科普和最终成果。

书面有上述任务，不把条目顺序直接强制成最终唯一安装顺序；依赖、分台和自由度待确认。输入可用点选、拖动、按钮旋转或其他合适方式，但必须让玩家真实作出安装角度/受力判断，不能只播放预设动画。

## 4. 安装角度、卡牢与受力的未定条件

用户明确提出“什么角度能卡牢”尚不理解，并请设计条件。因此目前只确定**要有调整与可见后果**，未确定某个角度、容差、卡扣或锁定公式。不可擅写“某角度自动锁死”为客户定案。

需设计并确认：玩家旋转哪个部件、绕哪个轴、参考目标如何可见、允许的角度范围、卡牢如何判断、未卡牢何时倒塌，以及受力方向如何选、如何反馈。应为儿童可理解的条件，不要求精确工程计算。

安装角度是“怎样装入并固定”；左右试舵是“装完后是否能转”。现有 ±30° 是后者参数，不能替代前者。结构合上、桅杆稳定与舵可动的判断也不能混为同一按钮动作。

## 5. 成功、失败与视听表现

成功须选对结构、安装固定满足确认条件、舵能转动且固定件稳定、受力选择正确，最后展示平稳下水。只完成八次预设装配并左右点舵不足以证明全部新目标完成。

错误榫型应不能正确配合并给提示。桅杆未卡牢应可见松动/倾倒；角度不合导致不能稳定/正常转动，应指出原因；帆桁受力错误的具体后果需设计确认。模型倾倒和失败说明应指向出错连接，不能只弹文本。

失败即时/集中测试、局部调整/整关重开尚未统一；角度错误是否允许先试验再修正也未定。实际处理需让提示、按钮和状态一致。下水展示是第三关收尾，不据此新增第四个风浪挑战。

## 6. 科普、亲子与扩展

科普讲古代帆船桅杆固定、福船尾舵，帮助理解固定连接与可转机构、支撑方向；教材变体和真实古船工艺分开说明。不把简化间隙、游戏锁定或角度参数解释成制造公差/强度保证。

成人可辅助角度与受力思考，儿童选配和操作；不强制双人联机。书面通关古船卡、【扬帆舵手】成就与亲子展示保留，具体交付优先级待排定。

## 7. 当前实现与缺口

已有三个局部工作台、八件装配：桅座抹头、角腿、桅杆方脚、帆桁牙条、承托板、L 型穿榫舵架横撑、无叶圆舵轴、侧装舵叶。各步候选可选，错误类型拒装；装好后左右达到当前 ±30° 才完成，固定榫卯支架不随舵动。

缺递增干扰、关前混合识别、玩家安装角度与受力选择、未牢的倾倒和最终下水展示。当前只有局部工作台不能宣称已展示整艘完成帆船。夹头/粽角用途冲突尚待确认。

## 8. 边界条件与待确认

| 事项 | 必须确认 |
|---|---|
| 榫卯分配 | 按书面重排夹头/粽角，还是确认现有教学变体；穿榫与舵轴关系 |
| 候选规模 | 比第二关增加多少，哪些相似结构作干扰，是否保持同一材料池 |
| 角度与固定 | 操作对象、轴向、阈值/容差、卡牢状态、方向提示及倒塌触发 |
| 受力选择 | 如何作答、何谓合理、如何反馈错误及是否可调整 |
| 完成范围 | 桅杆/帆桁/舵之外，船帆、帆索和横木的模型/操作/动画边界 |
| 恢复与测试 | 即时/整关失败，局部修正/重开，试舵范围是否保留，目录返回 |
| 最终呈现 | 全船/局部过渡、下水动画/视频、终章与卡片成就 |

需验证未选/错选/重复、未装好先旋转或试舵、动画中换件、撤回或重开后的旧回调、课堂/目录往返、失败后输入和成功后再入。试舵只转应转的件，不应把固定架扭走；未满足固定条件不得因播放完动画提前通过。
