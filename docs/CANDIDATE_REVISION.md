# 第一关：选前观察与拖动试装（2026-10-28）

当前正式体验：从关卡目录进入第一关，结束开场教学后，点击「看榫头，挑木料」。

1. 未选择时，上方已经展示三种真实榫端和相连木料；右侧三件木料也同时可见。主视图只是结构参考，按钮均不默认选中，尚不能安装。
2. 看目标槽口、刻度与实物，选择榫型和木料 A/B/C。数字来自对应克隆网格的实际长度；横梁按整梁长标示，错误榫型的缩肩榫端则另标榫端长。100 格是 1 模型单位，并非历史实物厘米。
3. 按住木料的圆圈标记，沿箭头拖向槽口，接近后松手吸附。拖动空白处可限角旋转。底部「准备试装」只恢复清楚的工作角度，不会替玩家安装；直接拖木料也能开始。
4. 轻点、只拖一半、偏离路径、放到面板外、触摸取消均不会安装；未成功会恢复原位。错榫型在槽口外止挡并明确拒绝，不能穿过木料后停在孔里。
5. 正确榫型的三种长度都允许安装。长短不合适在最后检查时表现为不稳，可撤回纠正。装入动画结束后点击「继续搭建」，其余同类木料逐件播放原有插入动画；三处手动、七件自动规则未改变。
6. 「船匠的小故事」入口和既有内容保留，等待另行提供的查证文案，本轮未编写或替换故事。

原来的主场景圆点试装仍保留为兼容入口；现在主要提示引导在观察页拖动。九种原教学模型、第二及第三关玩法、第一关主场景几何和船坊背景未改。返回目录按钮改为与标题栏协调的「‹ 关卡目录」。

## 修复依据

旧类型卡只抽出榫头 mesh，丢掉肩部上下文；燕尾预览三角面朝向反转，呈现开盒/空心效果。新预览克隆完整船体构件，取景靠近榫端与肩部，保留木纹并强制实木不透明。仅修复闭合展示克隆的表面方向，顶点位置不变；原船体资源与正确配合尺寸没有被预览改写。开放网格不推断内外。

输入层 `assembly_drag_surface.gd` 与状态/规则分离，继承局部旋转输入；`candidate_preview.gd` 只展示，`length_candidate_gallery.gd` 只提供候选选择，`level01.gd` 通过原规则提交。新控件是普通 stage 的覆盖层，与 SubViewportContainer 并列，避免输入被嵌套视口吞掉。
