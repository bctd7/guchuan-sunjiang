# 第二关：船板合壳

独立场景 `res://levels/level02/level02.tscn`；规则、状态、视图、输入、UI 分离。public `state/view/panel`；导航信号 `level_completed`、`return_requested`。

二维结构见 `level02-structure.png` 和 `level02-joints.png`。船长轴为 X；长 8；三列端缝示例 -1.40、+1.40、-1.40，相邻错开 2.80。板列宽 .78、板厚 .18；企口舌深 .09、厚 .06，槽深 .10、厚 .07。长水平拼边不算端缝。玩家观察展开图和真实船材槽口后选择候选，按底列到舷列铺装。

共十次放置：三列各左右两板，搭扣上框，扣合中撑与顶撑，隔舱板。固定下框位于 X=-2.8；两材正交，各刻半，总厚 .24。三向撑位于 X=+2.5；三根横材在水平面中 0°/+60°/-60° 相交，交叠区分别留底/中/顶三分之一，沿 -Y 先中后上落入。隔舱板在 X=0。

端缝对齐允许试装，验收出现红色端缝和水滴风险示意；“修正端缝”撤回到首个错误板列再铺。木榫本身不保证水密；隔舱/壳板展示为教学组合，需要填缝、密封与实体试水。几何验证涵盖占据体积、交叠区、静态插入路径；不宣称历史原位或工程强度。
