# 第一关：船肋表面、逐件动画及拾取修复

这轮修复保留船体轮廓、木材风格、榫头尺寸、正确配合规则和三处玩家操作、七件自动补齐的安排。

## 船肋为什么出现三角片

镜像后的船肋封面与侧壁绕序不一致，部分三角面从外侧被剔除。上轮预览整体翻面没有解决局部方向冲突。本轮在几何生成器中统一边界方向，让封面与侧壁真正连成实体，不再用双面材质掩盖。六根船肋保留原轮廓点、宽厚及孔槽。

同一检查发现长度模型中的燕尾封面方向，以及横梁钻孔段接缝内部重合壁也需纠正；已修外向表面并移除内部重合壁，保留真实通孔及原尺寸。预览只对方向一致的闭合网格推断内外，拒绝对损坏网格整体翻面。

## 现在如何拖动

先在观察页选择榫型和木料。**按住木料任意可见的实心部分**即可拖动，包括远离榫头的船肋和横梁端部；无需只抓小圆圈。按下时就锁定这一手势，拖过空白也不会变成旋转。空白处开始拖动则一直旋转，不会在途中抓走木料。

未选好时，按住参考木料会提示先选择，相机不乱转，也不默认选择。孔洞、前方不透明木料和按钮都不会被当成可拖木料。鼠标和触摸共用同一判定，并处理取消、失焦和合成鼠标去重。

**吸附阈值保持原值**：仍需沿插入路径拖动并在入口附近松手。到达可试装位置时显示「松手试装」；错榫型仍在槽外止挡，长短均可安装，长短不合适仍在稳定检查时反馈。

## 七件自动木料

旧版已有逐件 tween，但镜头只预留最后骨架范围，部分起点落在画面外，快速减速又令动作不清楚。现在每组镜头固定并容纳完整路径，每件包含 0.14 秒起点停顿、1.50 秒插入、0.12 秒就位停顿，完成后才轮到下一件。等待装入的实体先隐藏，不会提前在终点闪现；全组结束前不能检查稳定，撤回和重置会取消剩余动作。

## 实际验证与限制

六根左右船肋均检查默认及旋转后的 GPU 实际画面。整关操作通过真实 Viewport GUI 分发鼠标与触摸事件，从木料远离榫头的位置开始拖动；录下七件自动木料的实际帧和姿态，覆盖纠正后通关及错误长度不稳。网格另检查逐面法线、16 个视向首交、轮廓尺寸、真实孔道及预览不改源资源。

这些是后台实际渲染与 GUI 事件测试，**不是人工鼠标或实体触屏验收**。本轮没有操作用户桌面，实体触屏仍待现场验证；第二、三关完整装配未在本轮重跑。

证据目录：`tests/evidence/rib-repair/`。`automatic-ribs.gif`、`automatic-stern.gif`、`automatic-beam.gif` 由真实渲染帧制作，`report.json` 保留原帧时间与运动姿态。六根船肋的 `*-closeup.png` 为直接读取局部 3D 视口的实际像素。
