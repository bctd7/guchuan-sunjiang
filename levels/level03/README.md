# 第三关 · 港湾码头

从章节目录进入「帆樯舾装」，完成教学介绍后开始搭建。场景入口为 `res://levels/level03/level03.tscn`。

| 工作台 | 操作 |
|---|---|
| 龙骨桅座 | 用夹头榫装入横牙条与承托板，再落下方桅脚。试装错桅脚会看到桅杆倾斜，可以就地改选。 |
| 桅顶帆桁 | 合上粽角榫，判断帆重向下时角撑应该放在哪一侧。 |
| 船尾舵架 | 用穿榫固定横撑，调整舵轴与轴孔的夹角，再从侧面合上舵叶。 |
| 港湾试航 | 返回船架分别打左舵、右舵，点「下水试航」。整船驶离码头后显示「扬帆舵手」结果卡。 |

方向题使用离散选项，试航使用固定动画。帆布和索具随木件呈现。实施前的策划讨论与扩展范围见[第三关需求记录](../../docs/current/LEVEL03_REQUIREMENTS.md)。
