# 第2关：船板合壳

> 2026-11-08 当前第二关只采用两种装配结果：能继续则保留实际木件和原选项继续；不能继续则完成可达接触动作后自动弹出失败并提供重开。选错本身不触发提前失败，已能装齐的错口保留到试浪。取消“受阻后手动结束”流程。选材 UI 采用第一关式实体卡直接对照：缺口默认朝正面，参照和 A/B/C 共用同一比例，在实际缺口旁标关键尺寸。企口从下边量槽口高度，搭扣比较宽与深，扣合比较宽和居中／偏旁；仍可旋转、放大完整木料。上方参照对应实际试装接头：首处搭扣量取真实座木截面，配套扣合不套用后段标准尺寸；无对应量的接法只提示实际接合形状。三组、四次正常拖动、十件记录保持；第一处错选搭扣/扣合仍完成局部接头后报“拼装错误”。 见[本轮验证](../../tests/LEVEL02_UNIFIED_FIT_VERIFICATION.md)。 最新选材显示见[正面缺口与同尺度参照](../../tests/LEVEL02_DIRECT_COMPARISON_VERIFICATION.md)。

2026-11-09 交互复查：候选滚轮让三张卡和上方参照同步缩放；现有重置入口同时恢复正面对照；“放大”自动容纳完整木料。标线不会越过模型区域遮挡文字。见[复查记录](../../tests/LEVEL02_DIRECT_COMPARISON_VERIFICATION.md)。

总览任务卡进入共享观察页。顶部选择榫型，右侧沿用第一关的三行实体卡、字号和放大入口。缺口默认正对视线，参照与 A/B/C 使用同一模型比例和测量基准：企口比较从下边到槽口中心的高度，搭扣看实际缺口宽和深，扣合看宽度及居中／偏旁。尺寸线落在候选实体旁，手动旋转时隐藏；放大始终显示完整木料。上方参照对应实际接收木料，首处搭扣量取真实座木，首处配套扣合省去不存在的标准目标，后段顶撑显示实际已装两件的截面，包括保留下来的错口。见[验证](../../tests/LEVEL02_DIRECT_COMPARISON_VERIFICATION.md)。

正常流程为三组、四次拖动：整组企口铺板示范一块，自动补齐另外五块；搭扣框示范一次，自动补齐同缺口规格的隔舱板；扣合中撑侧推、顶撑下压各一次。船板采用 A/B/A 错缝排布。每个自动件仍独立检查真实接收边和装入路径，继承原选材并记录来源；撤回按整组操作。

选择、旋转和浅推不判错。完成有效拖入后的结果只有两种：

- 能继续：按实际接触姿态保留木件，后件检查真实前件。企口 A/C、搭扣 A/B 等可继续的错误不会被补齐逻辑修正，装齐后再试浪。
- 不能继续：木件到达真实接触处后自动弹出“组装失败”，保持接触画面，提供重开或回目录。没有 `jammed`、手动结束或失败后继续装后件的流程。

第一处错误搭扣和扣合先完整装完本处；扣合必须侧推中件、下压配套顶件后，才因不能形成连续船板接边弹出“拼装错误”。后面的中撑 A/B/C 都能先滑入下件；A/B 的上口在顶件安装时暴露阻挡。中撑 C 与顶撑 A 完整扣合。内部支撑松动在试浪时晃动，不凭空产生船壳漏水。

`assembly_policy.gd` 只有 continue/blocked 两种结果；`level_state.gd` 保存实际选择、安装及终局状态；协调器把规则与真实几何检查合并，手动件和自动件走同一检查入口。`hull_view.gd` 管实体接触、后续接口和表现，不以答案编号代替扣合顶件是否落座。几何构造器输出尺寸元数据，`opening_reference.gd` 读取当前接合结构的固定目标，`opening_dimensions.gd` 格式化候选尺寸，`opening_measure_panel.gd` 共用候选默认比例，`opening_measure_marks.gd` 投影尺寸标线，`opening_section.gd` 读取已装木料的实际截面；均只读呈现，不参与判错。

仍使用明亮木材、固定灯光、真实相邻船架和可返回的“看槽口”。课堂、海边船台、错缝科普及水密隔舱保留。海浪和几何检查用于教学，不是工程力学计算。
